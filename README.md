# KittyCraft — Pure-Rust ArtCraft Workstation

Desktop advisor, breed encyclopedia (kitten + adult portraits), care/medical/legal hub, diary, sitter calendar, and `Ctrl+J` AI advisor chat for cats and kittens.

## Launch

- Desktop app: `.\start.ps1` or double-click `start.bat`
- Smoke test: `.\start.ps1 -Smoke`
- MCP stdio server: `cargo run -p kittycraft-mcp -- mcp`
- Bundled skills CLI: `cargo run -p kittycraft-mcp -- skills list`

## Shortcuts

- `F1`: Handbuch & Kurzanleitung
- `Ctrl+J`: Katzi-Berater Chat Dock
- `Ctrl+K`: Command Palette
- `Ctrl+Wheel` / `Ctrl+=` / `Ctrl+-` / `Ctrl+0`: UI Zoom
